# Expanded model badges

Eight individual badges generated with the built-in image generation tool. Each uses an existing badge as a visual-family reference. The final prompts, reference paths and original PNGs are included here.

The WebP game assets are resized proportionally to a maximum of 320px with their original transparent backgrounds. They were inspected at 96px and 48px on the game's cream background. Names, prices and specifications remain HTML text.

The new ChatGDP, Clawed and Gemoney badges retain their existing family shapes. DeepShill uses a diving helmet; Midlife Journey combines a paintbrush and image frame; Slora uses a film-camera badge. Llamateur 32B is a three-module machine between the smaller and largest local-model illustrations.
