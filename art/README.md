# Bedroom illustrations

Six original 1536 × 1024 illustrations made with the built-in imagegen tool. Stage one established the composition, character and ink/gouache treatment. Each later image used it as an edit reference. Original PNGs are in `originals`; the game uses WebP encodings in `src/assets`. Encoding changes format only; it does not crop or redraw the artwork.

The exact prompt set is in `prompts.json`. Runtime light positions and accessible descriptions live in the room asset manifest. The original laptop, character, desk, window and room stay consistent; packaging, cable clutter, cooling and racks progressively consume the living space. The final stage adds an unused blazer, champagne and discarded green branding beside dead plants.

All artwork is packaged into the standalone HTML. No image requests leave the browser. Art changes do not change economy data or saves.
